# 数据/逻辑图统一视觉规范（matplotlib）

配图第 **④ 类** 专用：用 Python matplotlib 代码直接生成"讲数字/讲逻辑关系"的图。
目标是让全号这类图**风格统一、一眼认得出是同一个号**，而不是每篇各飘各的。

## 什么图走这条路（该用 ④）

- **数据图**：柱状 / 折线 / 占比 / 对比 / 趋势 —— AI 出图常把数字画错、坐标画歪，代码是精确的。
- **流程 / 管线图**：框 + 箭头 + 步骤（如"四步管线"）。
- **示意 / 概念图**：用简单几何图形讲一个抽象概念（如"盲区图：10 个点亮 4 个"）。
- **结构关系图 / 时间轴 / 对比表格图**。

共同点：要求**准、可复现、改一个数字重跑就行**。这正是代码的强项、AI 出图的软肋。

## 什么图不要走这条（回 ①/②）

- **封面 / 海报** → ① AI 出图。matplotlib 画出来是"工科 PPT 味"，撑不起爆文封面。
- **有人物 / 场景 / 隐喻的插画**（"一个人站在十字路口"）→ ① AI 出图，代码画不了。
- **网页 / 工具界面 / 真实截图** → ② 实际截图，不是画。

## 统一配色（硬规范，不许每篇乱换）

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景底色 | `#f7f4ec` | 米白，全图底色 |
| 主墨色 | `#2b2b2b` | 主要线条、文字、实心点 |
| 强调橙 | `#c9622c` | **只用于高亮/重点**，克制，一张图别超过 2-3 处 |
| 辅助灰 | `#7a7367` | 次要说明文字、注释 |

数据系列需要多色时，在墨色→橙色之间取同色系深浅，不要引入蓝绿红等杂色。

## 标准脚本头（每次画图直接抄，中文字体必设）

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# 中文字体必设，否则中文全是豆腐块（□□□）
plt.rcParams["font.sans-serif"] = ["PingFang SC", "Arial Unicode MS", "Heiti SC", "STHeiti"]
plt.rcParams["axes.unicode_minus"] = False

BG   = "#f7f4ec"  # 背景
INK  = "#2b2b2b"  # 主墨
ACC  = "#c9622c"  # 强调橙
GRAY = "#7a7367"  # 辅助灰

fig, ax = plt.subplots(figsize=(8, 5), dpi=160)
fig.patch.set_facecolor(BG); ax.set_facecolor(BG)
# ...绘图...
plt.savefig("output/<slug>/images/<文件名>.png", facecolor=BG, bbox_inches="tight")
```

## 版式约束

- **dpi ≥ 160**，`figsize` 宽高比按用途：正文配图 16:9 或 4:3，方图 1:1。
- **极简**：去掉多余边框刻度（`ax.axis("off")` 或只留必要坐标轴），留白充足。
- **图内文案禁令照旧**（与 ①②③ 同）：不放大标题、不放来源行、不放底部金句——正文里已有。图内只留图形必需的标签（数据数值 / 栏目名 / 一句说明小字）。
