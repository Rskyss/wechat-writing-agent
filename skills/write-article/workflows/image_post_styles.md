# 图文视觉风格库（Image Post Styles）

本文件只管微信「图片消息」的视觉风格选择与 Prompt 拼装。

- 图文内容、目录、事实核查和交付检查点以 `skills/write-article/workflows/image_post.md` 为准。
- 这里借用 Baoyu Skills 的风格、布局和 Prompt 结构，不调用它的外部图片 API。
- 默认只产出 Prompt；用户明确说“出图”后，才调用 Codex 内置出图能力。

## 一、固定品牌层

风格可以变化，下面这些规则不跟着变：

- 默认画布：`1080 × 1620 px`，`2:3` 竖版；用户指定其他比例时按用户要求。
- 阅读场景：手机连续滑图，每张图离开上下文也能独立读懂。
- 默认色板：温暖米白 `#F6F1E7`、深墨 `#20242A`、强调橙 `#F28C28`、辅助蓝灰 `#607284`。
- 中文字体感：接近 PingFang SC / 思源黑体；正文不使用难辨认的真实手写字体。
- 标题、页码、安全边距、圆角、图标线宽和底部导航在同一组图中保持一致。
- 手机端优先：标题大、正文短、层级少、留白足；不要靠放大查看才能读。
- 禁止：品牌 Logo、二维码、来源水印式标语、伪造界面、乱码、无关装饰、密集小字。
- 图内文字必须在 Prompt 中逐字列明，事实分寸不得超过 `copy.md` 和 `sources.md`。

## 二、风格选择流程

生成任何一组图文 Prompt 前，按下面顺序执行：

1. 判断内容属于哪一类：技术结构、概念科普、新闻解读、流程教程、产品界面、清单笔记、研究数据、人物故事或历史回顾。
2. 从本文件推荐 **3 种风格**：
   - 1 个默认推荐；
   - 1 个更亲切的选择；
   - 1 个更有传播冲击力的选择。
3. 展示每种风格的中文效果说明和适用理由，停下来等用户确认。
4. 用户已经明确指定风格，或明确说“按默认风格”，可以跳过风格确认。
5. 确认后，在图文目录创建 `style-spec.md`，记录：
   - 风格 ID；
   - 画布与色板；
   - 字体感；
   - 卡片、图标、线条和装饰规则；
   - 本组各页布局；
   - 禁止项。
6. 每张图的 Prompt 都要完整写入同一份风格锁定描述，不能只写“沿用上一张”。

## 三、8 个常用风格

这 8 个覆盖大多数 AI、产品和科技图文。没有特殊理由时，从这里推荐。

### 1. `notion`｜极简知识手绘

适合：概念科普、工具介绍、SaaS、生产力、知识清单。

Prompt 片段：

> 极简 Notion 知识卡风格，温暖米白纸张背景，深墨色手绘细线，圆角卡片，少量橙色荧光笔强调，图标像快速画出的工作笔记。标题和正文使用清晰印刷体，手绘感只用于图标、箭头和装饰线。

### 2. `sketch-notes`｜手绘笔记

适合：教程、方法总结、学习框架、轻量技术解释。

Prompt 片段：

> 手绘视觉笔记风格，纸张纹理轻微可见，结构像产品经理会议笔记，使用箭头、圈注、便签和小图标组织内容。中文正文保持清晰印刷体，不模拟潦草手写；橙色只用于关键结论和路径。

### 3. `editorial-infographic`｜科技杂志信息图

适合：新闻解读、报告拆解、趋势分析、证据密集型内容。

Prompt 片段：

> 科技杂志信息图风格，严格栅格、醒目的编辑式标题、细分隔线、数据注释和图片说明框。米白底配深墨正文、蓝灰结构线和橙色重点，信息密度较高但层级清楚，像一页可以收藏的科技杂志。

### 4. `blueprint`｜技术蓝图

适合：AI 架构、系统设计、技术栈、组件关系。

Prompt 片段：

> 浅色技术蓝图风格，精确网格、结构节点、调用线和分区标签，蓝灰色工程线条配少量橙色关键路径。保持米白底和手机端大字号，不使用深蓝满底，不添加无意义尺寸线或伪代码。

### 5. `technical-schematic`｜工程结构图

适合：Agent、工作流、系统拆解、机制解释、复杂流程。

Prompt 片段：

> 现代工程示意图风格，几何结构准确，连接关系清楚，节点、箭头、判断菱形和标注框使用统一线宽。米白底、深墨主线、蓝灰模块、橙色关键节点，带少量技术网格，但不做霓虹科技感。

### 6. `vector-illustration`｜现代矢量图解

适合：通用知识卡、产品介绍、对比、面向非技术岗位的科普。

Prompt 片段：

> 现代平面矢量图解风格，图形简洁、色块克制、人物和物件使用概括化轮廓，圆角卡片与清晰图标共同承载信息。整体友好而专业，不使用写实人物、复杂阴影或廉价商业插画模板。

### 7. `minimal`｜极简留白

适合：封面、单观点、金句、一个强结论、少量对比。

Prompt 片段：

> 极简编辑设计，至少 45% 留白，一个强视觉锚点，标题大而短，正文只保留必要信息。米白、深墨、橙色三色为主，不堆图标，不使用装饰性背景，不把少量内容硬填满画布。

### 8. `bold-editorial`｜高冲击编辑设计

适合：热点封面、反常识结论、产品发布、风险提醒。

Prompt 片段：

> 高冲击杂志封面风格，超大标题、强烈大小对比、少量粗线和橙色几何强调块。主体结论在 3 秒内可读，正文仍保持克制；不用夸张爆炸贴纸、廉价渐变、霓虹光效或密集感叹号。

## 四、10 个场景风格

这些风格只在内容匹配时推荐，不作为通用默认。

### 9. `ikea-manual`｜极简说明书

适合：操作步骤、安装流程、教程、故障排查。

Prompt 片段：

> IKEA 组装说明书风格，黑色极简线稿、编号步骤、明确动作箭头、少量橙色警示标记。每一步只画一个动作，视觉语言统一，避免真实软件截图和多余背景。

### 10. `subway-map`｜地铁线路图

适合：多路径工作流、分支、并行、汇合、时间路线。

Prompt 片段：

> 地铁线路图风格，不同任务路径用有限颜色区分，节点像站点，分支、并行、汇合和终点清楚可追踪。线路不能交叉混乱，橙色用于主路径，蓝灰用于支线。

### 11. `ui-wireframe`｜产品线框图

适合：产品界面、SaaS、交互流程、功能拆解。

Prompt 片段：

> 产品 UI 线框图风格，灰度界面框架、清晰组件层级、少量橙色交互焦点和蓝灰色状态。画面像设计评审稿，不伪造真实品牌界面，不放难以辨认的小按钮文字。

### 12. `study-notes`｜学习笔记

适合：清单、复习卡、概念速查、知识总结。

Prompt 片段：

> 整洁学习笔记风格，蓝色细线、红橙圈注、黄色或橙色荧光笔、便签与简洁小图标。正文保持清晰印刷体，只模拟“整理好的笔记”，不模拟凌乱真实手写和拍照阴影。

### 13. `chalkboard`｜黑板粉笔

适合：课堂科普、基础概念、教育型内容。

Prompt 片段：

> 深色黑板与彩色粉笔风格，白色主文字、橙色与浅蓝重点、简洁粉笔图标和箭头。粉尘纹理要轻，中文必须清晰，避免整页过暗或用大量细小手写字。

### 14. `craft-handmade`｜纸艺手作

适合：轻松科普、生活化解释、亲切的方法论。

Prompt 片段：

> 手工纸艺信息图风格，米白纸张、轻微剪纸边缘、手绘图标和层叠卡片，质感温暖但不幼稚。阴影非常轻，信息结构仍以清晰栅格和大字号为主。

### 15. `scientific`｜科学图表

适合：论文、实验、研究数据、医学与自然科学。

Prompt 片段：

> 科学出版物图表风格，标注精确、比例克制、数据和变量命名清楚，使用细线、图例和结构示意。米白底、深墨文字、蓝灰数据、橙色重点；不伪造统计数字，不添加装饰性科学符号。

### 16. `aged-academia`｜复古学术

适合：理论源流、历史科技、人物档案、思想史。

Prompt 片段：

> 复古学术档案风格，泛黄纸张、墨线素描、档案标签和少量橙褐色重点，像旧实验室笔记或历史资料页。做旧纹理不能影响中文阅读，不伪造印章、日期或历史证据。

### 17. `screen-print`｜丝网印刷

适合：热点海报、强观点、复古科技、传播型封面。

Prompt 片段：

> 丝网印刷海报风格，有限色板、粗颗粒网点、深墨与橙色套印感、醒目标题和简化图形。保持文字边缘清晰，不模拟错版到影响阅读，不使用过多颜色。

### 18. `watercolor`｜柔和水彩

适合：人物故事、生活、情绪、旅行、温和观点。

Prompt 片段：

> 柔和水彩插画风格，纸张留白、自然晕染、轻柔边缘和少量线稿，色彩温暖克制。文字区域保持干净平整，水彩只服务于场景和情绪，不承载复杂流程或精确数据。

## 六、风格与布局分开选择

风格控制画面气质，布局控制信息关系。不要用风格名代替结构设计。

常用布局：

- `sparse / hero`：封面、单观点。
- `grid-cards`：多个平级概念。
- `list / dense`：清单、速查。
- `comparison`：双栏或多项对比。
- `flow`：线性流程、时间顺序。
- `circular-flow`：反馈循环、持续迭代。
- `structural / layers`：系统拆解、架构层级。
- `subway / tree`：分支、并行、汇合。
- `timeline`：历史与事件发展。

推荐写法：

> `technical-schematic × circular-flow × 本号默认色板`

不要只写：

> 科技感流程图

## 七、整组风格锁定

同一组图必须锁定：

- 相同画布比例和安全边距；
- 相同背景、主色和强调色；
- 相同标题字号、正文层级和页码位置；
- 相同卡片圆角、边框、阴影和图标笔触；
- 相同的中文字体感；
- 相同的插图角色造型；
- 相同的导航方式。

允许变化：

- 每页信息布局可以按内容在 grid、flow、comparison 等结构间切换；
- 第一张封面可以更强，但不得切换成另一套画风；
- 重点色占比可以变化，不能更换整套色板。

## 八、不作为日常默认的风格

以下风格只在用户点名或题材高度匹配时使用：

- `cute / kawaii`：容易偏成少女卡片。
- `claymation / lego-brick / origami`：画面有趣，复杂中文和严谨结构承载力弱。
- `cyberpunk-neon`：容易出现通用 AI 科技感，暗底也影响手机阅读。
- `pixel-art`：只适合游戏、复古开发者题材。
- `fantasy-animation`：适合故事，技术解释容易被画面抢走。
- `manga / shoujo / wuxia`：属于知识漫画路线，不作为普通图文默认。
- `realistic`：人物一致性与图中文字控制成本高。
- `corporate-memphis`：容易变成没有辨识度的商业模板。

## 九、Prompt 拼装顺序

每张图的 Prompt 按下面顺序写，缺一项都可能导致整组漂移：

1. 任务：微信公众号图片消息中的第 N 张图。
2. 画布：尺寸、比例、手机阅读。
3. 固定品牌层。
4. 已确认的风格 Prompt 片段。
5. 本页布局和信息流向。
6. 图内文字逐字清单。
7. 图形、图标、节点和箭头要求。
8. 与上一页保持一致的具体规则；不能只写“同上一张”。
9. 禁止项和文字准确性要求。

## 十、当前 Agent 三件套示例

推荐组合：

> `technical-schematic × 米白墨橙色板`

各页布局：

- 总览：`grid-cards`
- Harness：`structural`
- Loop：`circular-flow`
- Graph：`flow + branch`

备选：

- 更亲切：`notion × 米白墨橙色板`
- 更像科技杂志：`editorial-infographic × 米白墨橙色板`
