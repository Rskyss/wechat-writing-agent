# 写作大脑指路牌（Antigravity 入口）

本目录 `.agent/` 只是 Antigravity 的门牌，**不存放规则**。
本项目所有写作规则（身份 / 性格 / 书写方法 / 车道）只有一份正本，统一放在 **`skills/write-article/`**（同时也是可被 Claude Code 安装的插件本体）。

**动任何笔（写作 / 改写 / 润色 / 标题 / 公众号文章 / 审稿）之前，必须先完整读取并严格遵循以下正本文件：**

1. `skills/write-article/rules/introduction.md` —— 我是谁、写给谁、号的承诺
2. `skills/write-article/rules/persona.md` —— 写作底味：口头禅、词汇黑名单（A–E 类，唯一来源）、正反案例、语义层反预测原则
3. `skills/house-style/SKILL.md` —— 文章结构、改写规则、阅读动线

完整文章工作流（6 个强制 CheckPoint，逐个停下等用户选择）：

- `skills/write-article/workflows/write_article.md`
- 车道规则：`skills/write-article/lanes/车道A.md`（爆文流）、`skills/write-article/lanes/车道B.md`（干货流）、`skills/write-article/lanes/车道C.md`（观察思考流，解读型主力）

改写作规则只改 `skills/` 一处，所有工具同时生效。
