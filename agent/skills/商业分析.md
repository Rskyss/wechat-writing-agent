# 商业与深度分 (The "36Kr/LatePost" Lens)

当选题涉及**金钱、战略、行业变革或大公司博弈**时，必须使用此技能。
不要在简单的工具评测或教程中使用。

## 核心哲学：洞察 > 信息
- **铁律**: 把讨论从 "发生了什么" 提升到 "这对未来/钱/权力意味着什么"。
- **目标**: 让读者觉得这篇文章"有段位"，值得作为谈资和社交货币。

## 深度弧光 (强制结构)

在使用此模式写作时，必须构建以下结构：

### 1. 现象定义 (The Phenomenon)
- **技巧**: 定义 "新常态" 或 "范式转移"。
- **核心能力**: **造词 (Concept Coining)**。不要用普通的话，要创造或引用一个有传播力的词。
    - 示例: "AI 界的拼多多时刻" (DeepSeek) 或 "智能 OS 之战" (ChatGPT)。
- **焦点**: 为什么这次不一样？

### 2. 底层逻辑 (The Deep Dive)
- **技巧**: 使用 "第一性原理" 思考。
    - **成本**: "边际成本归零"、"摩尔定律失效"。
    - **结构**: "组织 vs 个体"、"协作成本"。
    - **护城河**: "数据是石油 -> 上下文是石油"。
- **对比**: "旧时代的逻辑 (SaaS)" vs "新时代的逻辑 (Agent)"。
- **数据支撑**: 必须用数字证明这种剧变 (例如 "1/70 的推理成本")。

### 3. 终局推演 (The Deduction)
- **技巧**: 大胆推演未来 3-5 年。
- **焦点**: 谁会赢？谁会输？什么是这场游戏的*必然*结局？
- **示例**: "SaaS 已死，Service 永生。"

### 4. 行业行动呼吁 (The Meaning)
- **技巧**: 企业/领导者现在该做什么？
- **焦点**: 战略转型或思维重构。

## 写作技巧

### A. 定义权 (Concept Coining)
- 使用比喻来简化复杂的商业模式。
- "它是 X 领域的滴滴。"
- "这不是工具，这是你的新同事。"

### B. 上帝视角 (Macro Perspective)
- 引用历史平行线 (例如 "就像 2010 年的移动互联网爆发前夜...")。
- 引用 "Big Players" (Google, Microsoft, OpenAI) 来设定战场。

### C. 分析型关键词 (用于建立权威感)
- 范式转移、飞轮效应、护城河、单位经济模型、分形、去中心化、降维打击。

## 商业模式禁忌
- ❌ 情绪化宣泄 ("我觉得这很可怕...")。要客观、冷峻、逻辑严密。
- ❌ 简单的功能列表 ("它有一个聊天窗口")。关注 *价值*，而非 *功能*。
